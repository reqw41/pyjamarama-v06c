# Логотип «Pyjamarama!» — ручная правка

**Проще всего — через HTML-редактор: откройте `art/logo_editor.html` в браузере** (Chrome/Edge). В нём оба холста, палитры, карандаш/линия/рамка/заливка/пипетка, отмена, сдвиг стрелками, подсветка смешанных ячеек/колонок, режим «как будет в игре» и счётчик памяти. «Сохранить в папку art…» пишет оба PNG напрямую (иначе «Скачать PNG» и положить в `art/`). Затем `sh tools/rebuild.sh`. Редактор пересобирается из текущих PNG: `python3 tools/logo_editor_pack.py`.

Два файла, которые вы правите в любом растровом редакторе (Aseprite, GIMP, Krita, Photoshop). Если файл существует, он **заменяет** генератор (`tools/mktitle.py`).

| файл | размер | что это |
|---|---|---|
| `logo_title.png` | 256×64 | логотип заставки. Левый верх холста = точка (0, 120) на экране 256×192; ниже (строки 184..191) — надпись «PRESS A KEY…» |
| `logo_game.png` | 256×32 | нижняя полоса игры 1:1 (под игровым полем). Холст = вся полоса |

Заготовки: `python3 tools/logo_export.py` (слитный логотип C64) или `python3 tools/logo_export.py layout` (текущая раздельная раскладка). **Перезапишет ваши правки** — сначала сделайте копию.
Сетка ячеек 8×8 для ориентира: `art/logo_title_guide.png`, `art/logo_game_guide.png` (в сборке не участвуют, пересоздаются экспортом).

## Правила рисования
- **Фон** — прозрачный или белый (≥235 по всем каналам); для игры фоном считается ещё и тёмный (все каналы <70). Всё остальное — чернила. Рисуйте обычными цветами, сборка берёт ближайший цвет палитры:
  - заставка (оригинальные цвета ZX): чёрный (0,0,0), синий (0,0,205), красный (205,0,0), пурпурный (205,0,205), зелёный (0,205,0), циановый (0,205,205), жёлтый (205,205,0).
  - игра (палитра PICO-8): жёлтый (255,236,39), красный (255,0,77), голубой (41,173,255), зелёный (0,228,54), фиолетовый (182,109,255), оранжевый (255,182,0), коричневый (219,146,85).
- **Игра: цвет попиксельный** — любой пиксель любого из 7 цветов (три плоскости, сжаты ZX0). Чем проще картинка и меньше размер (колонки×строки), тем меньше памяти (сейчас ≈360 Б).
- **Заставка: цвет ячейки 8×8 — преобладающий, остальные пиксели — «исключения»** (хранятся отдельным списком, по 4 байта, не больше 255; сборка печатает их число). Сейчас 43.
- Размер холста менять нельзя (проверяется). Низкая память: запас ≈200 Б.
- Заставка: у надписи под логотипом (строка 23) свой цвет, трогать не нужно.

## Сборка
```
sh tools/rebuild.sh        # mkvecdata + mktitle (читает art/*.png) + сборка образа
```
Предпросмотр: заставка — `build/vec/title_color_preview.png`; игра — запустите образ (`sh tools/emu80_run.sh`) или `node tools/vecflow.js "300:key space+ 310:key space- 700:shot /tmp/game.png" 710`.
