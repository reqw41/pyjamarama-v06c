# Заставка: раскраска внешней моделью

1. Возьмите `art/title/lineart.png` (1024x768, чёрно-белый рисунок ZX-экрана; он же 256x192 — `lineart_1x.png`).
2. Попросите модель/художника раскрасить (подсказка ниже), результат сохраните как `art/title/colored.png` (любой размер с тем же соотношением 4:3; лучше 1024x768).
3. `PJ_LANG=ru sh tools/rebuild.sh` — пиксели станут ближайшими цветами палитры (8 цветов, `art/title/palette.py`), чёрные контуры оригинала (`outline_1x.png`) останутся тёмно-фиолетовыми.
   Диффузия ошибки: `PJ_DITHER=1 sh tools/rebuild.sh` (даёт полутона, но шумнее). Превью — `build/vec/title_preview.png`.
4. Если раскраска не нужна — удалите `colored.png`, вернётся правленая раскраска из `fixes.py`.

Палитра (используйте только эти цвета, без градиентов и сглаживания): тёмно-фиолетовый контур #180E2C, синий #465AFF, коралловый #EB3C46, розовый #FF78C8, мятный #3CC88C, голубой #78DCFF, золотой #FFC846, кремовый #FFF5E1.

Готовый самодостаточный промпт (русский и английский) — `art/title/PROMPT.md`. Краткая подсказка: «Раскрась этот чёрно-белый пиксельный рисунок из игры Pyjamarama (ZX Spectrum): спальня, люстра, шторы, кровать, сонный герой Уолли в пижаме. Только 8 плоских цветов из списка (...), без сглаживания и градиентов, пиксельный стиль 256x192, контуры оставь нетронутыми, цвета сгруппируй по предметам: стены кремовые, потолок мятный, шторы и ковёр коралловые, кожа и волосы золотые/кремовые, пижама кремовая с синим».

## Квадратная картинка (как сейчас)
Если `colored.png` почти квадратная (так вернула модель, 1254x1254), она ставится 192x192 по центру, по бокам белые поля 32 пикселя. Блок исходных пикселей даёт один пиксель: контур (>=22% тёмных) приоритетнее, иначе самый частый цвет палитры. Палитра `palette.py` подобрана по этой картинке; прежняя (по ZX-экрану) — `palette_zx.py`.
