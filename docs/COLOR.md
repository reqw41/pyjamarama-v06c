# Раскраска: по мотивам ремейка MinionSoft (PICO-8, 2023)

Источник: видео nX9sHEHToEc (геймплей, 13 мин). Кадры: ref/color/f001..f259.png (раз в 3 с), контактные листы ref/color/sheets/s01..s13.png.
Ремейк и его графика — не наши; берём только цветовую схему (палитра PICO-8) и принципы раскраски, спрайты рисуем сами из ZX-оригинала.

## Цветовая схема ремейка (по кадрам)
- Фон всех комнат — тёмно-синий (вместо чёрного ZX); шапка со статусом (LIFE, SNOOZE ENERGY, карманы) — на чёрном.
- Потолок и боковые стенки — красные (потолок с розовой/светлой кромкой), пол — голубая полоса. В ZX это атрибуты 0x43/0x42 (потолок/стенки) и 0x45 (пол).
- Мебель раскрашена по предметам: кровати/стулья/диваны/перила — зелёные, шкафы/ванна/свечи/ключи — жёлтые, двери — коричневые или
  белая рама с красными стёклами, столы — красно-розовые, бочки — серые/красные, ангелы и кусачие — красные.
- Wally жёлтый (в ремейке утёнок; у нас оригинальный Wally, но жёлтый, пижама можно красным/розовым).
- Особые комнаты: «красная» комната (полосатые красные стены, бар/бочка) — отдельная схема; аркада с зелёными захватчиками.

## Палитра Вектора (8 цветов, 3 плоскости)
Байт палитры Вектора: BBGGGRRR (R 0–2, G 3–5, B 6–7); при записи в порт учитывать инверсию/порядок как в других портах (cpcpal.vecbyte в aticatac-v06c).

| № | Назначение | Цвет PICO-8 | Байт палитры |
|---|---|---|---|
| 0 | тёмно-синий (фон комнат) | #1D2B53 | 0x49 |
| 1 | красный (потолок, стенки, плинтус, ловушки) | #FF004D | 0x47 |
| 2 | голубой (пол, вода, шар) | #29ADFF | 0xE9 |
| 3 | зелёный (кровать, стулья, диван, перила) | #00E436 | 0x70 |
| 4 | жёлтый (Wally, шкафы, ванна, свечи, ключи) | #FFEC27 | 0x37 |
| 5 | белый (текст, молоко, раковина, дверные рамы) | #FFF1E8 | 0xFF |
| 6 | коричневый (двери, горшки, бочки-корпус) | #AB5236 | 0x55 |
| 7 | розовый (столы, стол-ножки, ангелы, надпись SNOOZE ENERGY) | #FF77A8 | 0x9F |

Серый PICO-8 (бочки, решётки) → белый или коричневый; оранжевый (шары, мяч) → жёлтый/коричневый. Чёрного нет: рамка и шапка — тёмно-синий.

## Как красить (план)
1. Логика остаётся на атрибутах ZX (коллизии, фон под Wally). Цвет — только в рисовалке по журналу примитивов.
2. Тайлы (`tile`/`flip`/`dbl`): цвет по таблице «атрибут ZX → цвет Вектора» (0x42/0x43 → красный, 0x45 → голубой, 0x46 → жёлтый, 0x47 → белый и т.д.).
3. Спрайты 16×16 (`bmp`): таблица «индекс спрайта → раскраска по пикселям»: маски цветов по частям (Wally: лицо, пижама, тапочки; предметы по образцу ремейка).
   Три плоскости без клэша: пиксель берёт цвет своего спрайта; стирание XOR только в плоскостях спрайта.
4. Фон: заливка тёмно-синим (плоскости: цвет 0 = синий) и красные/голубые края.
