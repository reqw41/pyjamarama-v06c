ядро переводчика общее с **kvalley-v06c**. Локальные клоны — `~/projects/<имя>`.

## Рецепт и журналы
- `knightlore-v06c/docs/PORT_RECIPE.md` (+ `PIPELINE.md`) — главный рецепт переноса ZX-игры: §1 разведка точек соприкосновения с железом,
  §2 раскладка памяти Вектора, §3 склейка (загрузка, прерывание, палитра, клавиатура, бипер→очередь ВИ53, ограничители таблиц),
  §7 грабли столбцового буфера, §8 что ломается при рекомпиляции (хелперы `(ix+n)` не должны работать при SP в данных; ORG-регионы),
  §9/§16 звук на ВИ53, §10 атрибуты ZX, §12 стековый вывод, §13 гейт картинки, §17 экономия памяти (плоскость 2 свободна, дыры вне картинки),
  §21 поиск зависаний, §22 самопроверка гейтов, §25 джойстик «П» (порт 6).
- `alien8-v06c/docs/PORT_RECIPE.md` — то же на втором движке (числа, грабли); `DEVLOG.md`, `SPEED_PLAN.md`.
- `jetpac-v06c/docs/LOGIC_PLAN.md` — наш подход «JS-модель → i8080», сверка с ZX по шагам, 3 плоскости без клэша, вывод на SP.

## Переводчик Z80 → i8080 и гейты
- `knightlore-v06c/tools/kl_z80_to_8080.py` — ядро (из kvalley-v06c/tools/kv_z80_to_8080.py): развёртки `jr/djnz/bit/set/res/сдвиги/ldir/adc,sbc hl/neg/ld a,r`,
  **компактные хелперы IX/IY** (`call il_ix_* + inline-байт`, функции `_ixiy_compact`, `ix_helpers_text`), `ld (nn),sp`; в проекте — `tools/vendor/z80_to_8080.py`
  (то же ядро без склейки; компактные IX — взять из KL, когда не хватит памяти).
- `knightlore-v06c/tools/check_i8080.py` — гейт «в образе нет опкодов Z80» (08/10/18/2x/3x/CB/D9/DD/ED/FD); `tools/gatecheck.py` (alien8) — самопроверка гейтов порчей.
- `scubadive-dx-v06c/tools/z80to8080.py` — отдельный общий переводчик (аудит расхождений флагов, план IX), `quazatron-v06c/tools/port8080.py` — полный конвейер от снимка ZX.

## Склейка с железом Вектора (в строках KL: `VEC_HEADER`, `VEC_TAIL`, `vec_scan`, `vec_zxbuild`, `VEC_ZXMAP`, `vec_joy`)
- Загрузка `.r0m` с 0x0000: `out(0),0x88`, бордюр `out(2)`, скролл `out(3),0xFF`, ВИ53 `out(8),0x30`; палитра — только в VBlank (RST 38h), в ISR каждый кадр
  4×`out(0x0C)` на запись, индекс — через порт 2; клавиатура опрашивается в начале ISR (порт 3 = скролл = выбор ряда!), матрица `vec_kbmat` → ряды ZX (`vec_zxrows`)
  по таблице `vec_zxmap`; `IN A,(0xFE)` заменяется чтением этих рядов; джойстик «П»: `out(4),0x83`, `out(5),0x9F`, `in(6)`, покой замеряется при старте.
- Звук бипера → очередь нот на ВИ53 (§16): делитель и длительность в 1/256 кадра; ISR раз в кадр списывает и переключает ВИ53.
- Свободные плоскости: палитра игнорирует плоскость 3 (и 2, если цветов ≤4) — там можно держать код/данные; строки вне картинки (192 из 256) — «дыры» под код.
